## ✨ Key Features & Highlights

- 🖥️ **IDE-Themed UI & Design System**: A unique asymmetric layout inspired by modern code editors (VS Code / JetBrains) with custom syntax-highlighted color tokens and hardware-accelerated glassmorphism.
- ⚡ **Interactive Command Palette & Cyber Terminal (`⌘K` / `Ctrl+K`)**: Universal spotlight search and interactive terminal shell modal with fuzzy searching, keyboard navigation (<kbd>↑</kbd> <kbd>↓</kbd> <kbd>↵</kbd>), and executable CLI commands (`help`, `projects`, `skills`, `whoami`, `neofetch`, `sudo hire`, `goto`).
- 💼 **Enterprise Experience Showcase**: Dedicated enterprise role breakdown as a **Full-Stack Developer Intern at Periscale AI**, featuring detailed cards for production e-commerce platforms and server-side analytics engines.
- 🔬 **IEEE-Published Research & Citation Drawer**: Dedicated academic showcase for peer-reviewed medical AI paper (**3C-Net** in IEEE Xplore) with 1-click **BibTeX** and **APA** citation copying drawers.
- 📄 **Interactive In-Browser CV Modal**: Full-featured resume preview modal with direct PDF download (`Ahnaf_Rasheed_CV.pdf`), pop-out tab support, and <kbd>Esc</kbd> keyboard dismissal.
- 🎡 **Dynamic Projects Showcase & Dual View**: 11-project filterable showcase with interactive carousel slider, grid matrix view, category chips, tech stack sub-filters, and verified live demos/repositories.
- 📊 **Live GitHub Activity Telemetry**: Annual contribution matrix, real-time repository telemetry, language distribution meters, and `sessionStorage` caching to prevent rate-limiting.
- 🌿 **Git-Log Qualifications Timeline**: Academic roadmap rendered as an interactive Git commit graph (`git log --graph --oneline`), complete with branch curves, commit hashes, and tag badges.
- 🎢 **Infinite Tech Marquees**: Dual-direction, seamless marquee rows displaying frontend, backend, database, and devops proficiencies.
- 🌌 **Optimized Reactive Particle Background**: Canvas-based interactive particle network responding dynamically to cursor physics with mobile frame-throttling and zero memory leaks.
- 🧭 **Modern 3-Column Footer & IDE Status Dock**: Comprehensive navigation directory, live project availability pulse badge, developer social links, and real-time IDE telemetry dock.
- 📱 **100% Mobile & Touch Optimized**: Drawer navigation, touch-friendly swipeable cards, fluid typography, and iOS auto-zoom prevention.

## ⌨️ Command Palette & CLI Terminal

The portfolio includes a developer-first command palette modal that can be toggled anywhere on the site:

### Hotkeys & Triggers
- **Keyboard Shortcut**: Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or <kbd>Cmd</kbd> + <kbd>K</kbd> on macOS) or <kbd>`</kbd> (backtick).
- **UI Triggers**: Click the **Terminal [⌘K]** button in the top navbar, mobile navigation drawer, or the system status bar in the footer.

### Executable Commands
- `help` — Render interactive Command Matrix cards with click triggers.
- `whoami` / `about` — Display developer ID badge and bio.
- `skills` — Render categorized visual skill radar grid.
- `projects` — Display rich project cards with live links and repository shortcuts.
- `cv` — Launch the in-browser resume preview modal.
- `neofetch` — Display ASCII system telemetry & developer specs.
- `contact` / `socials` — Interactive contact cards with 1-click email copy.
- `goto <section>` — Jump directly to `hero`, `about`, `experience`, `projects`, `research`, `skills`, `education`, or `contact`.
- `sudo hire` — Access granted easter egg and fast-track to contact form.
- `clear` / `exit` — Clear terminal buffer or close modal.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### 1. Clone the repository
```bash
git clone https://github.com/ah-nd-naf/Portfolio_Ahnaf.git
cd Portfolio_Ahnaf
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables (Optional)
Create a `.env` file in the root directory if you wish to configure your custom Web3Forms access key for direct email delivery:
```bash
# Copy example environment configuration
cp .env.example .env
```
Inside `.env`:
```env
VITE_WEB3FORMS_ACCESS_KEY=your_web3forms_key_here
```
*(Note: A reliable client fallback is pre-configured, so contact submissions work out-of-the-box even without a custom key).*

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for production
```bash
npm run build
```
